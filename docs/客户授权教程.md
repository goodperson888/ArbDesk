# ArbDesk 客户授权教程

## 第一次授权

1. 打开 ArbDesk。
2. 软件会直接显示“安全授权入口”，未授权时不会进入交易功能页面。
3. 在页面中部找到“本机机器码”，点击右侧复制按钮。
4. 把完整机器码发给授权管理员。机器码以 `ARB-` 开头，例如：

   ```text
   ARB-XXXX-XXXX-XXXX-XXXX-XXXX-XXXX
   ```

5. 管理员会返回一个以 `ARB1.` 开头的授权码。
6. 把授权码完整粘贴到“授权码”输入框。
7. 点击“验证并进入软件”。验证成功后会自动进入 ArbDesk 主界面。

## 续期时在哪里找机器码

如果软件还可以正常进入：

1. 点击主界面右上角的设置按钮。
2. 打开“账户与环境”。
3. 展开“软件授权”。
4. 点击机器码右侧的复制按钮，然后发给授权管理员。

如果授权已经到期，软件会自动回到授权页面，直接复制页面中的“本机机器码”即可。

## 安全提醒

- 机器码可以发给授权管理员，它不是账户密码。
- 不要发送 MEXC 或 Polymarket 登录密码。
- 不要发送钱包助记词、交易私钥或 API Secret。
- 授权码只适用于生成时绑定的那台电脑，复制到其他电脑不能使用。
- 更换电脑或重装系统后，如果机器码发生变化，需要把新机器码发给管理员重新签发。
